Commands used to produce every file in this directory (Stage 14: schedule
attribution and backend-informed cost-model integration). All paths
relative to the ml-graph-compiler-runtime repo root unless absolute.

1. Load Stage 12 static/backend evidence and Stage 13 measured evidence,
   build provenance-tagged CandidateEvidenceRecords, run the full ranking
   experiment (3 modes x 3 matched groups), build attribution reports,
   classify every candidate, compute shape-aware findings, and write
   every artifact in this directory:

   python3 tools/run_aarch64_schedule_cost_model.py \
     --output-dir artifacts/backend_codegen/aarch64_matmul_bias_relu_schedule_cost_model \
     --schedule-candidate-mode calibrated \
     --emit-schedule-cost-breakdown \
       artifacts/backend_codegen/aarch64_matmul_bias_relu_schedule_cost_model/production_cost_breakdown_calibrated.json

   python3 tools/run_aarch64_schedule_cost_model.py \
     --output-dir /tmp/stage14_static_only \
     --schedule-candidate-mode static \
     --emit-schedule-cost-breakdown \
       artifacts/backend_codegen/aarch64_matmul_bias_relu_schedule_cost_model/production_cost_breakdown_static.json

   (--schedule-profile defaults to
   artifacts/backend_codegen/aarch64_matmul_bias_relu_pi_scheduling/pi_validation_results.json;
   --stage12-json defaults to
   artifacts/backend_codegen/aarch64_matmul_bias_relu_scheduling/schedule_comparison_results.json)
